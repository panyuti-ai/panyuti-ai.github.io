Latest · Python tool + Claude Code plugin

runsnap

When an AI cleans up code, the code is supposed to change, but the answers it gives are not. runsnap writes down every answer your functions give while the tests run, then checks each one again after the AI's edit. Here Claude Code tidied up the toolz library:

CLAUDE SAID

“Done. All 187 tests pass. Nothing changed.”

toolz's tests gave 22,404 answers that can be compared before and after the edit. Each square is 20 of them.

1 ANSWER CHANGED

Put 'a' between the items of an empty list: interpose('a', [])

Beforean empty list_iterator
After the AI's editan empty itertools.chain

Both are empty, so nothing breaks today, but code that checks the type would. Claude's tests and its own 17,000 random checks missed it. With the runsnap plugin, Claude saw this and put the original code back.
